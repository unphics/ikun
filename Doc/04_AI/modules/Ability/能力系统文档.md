# 能力系统文档

## 1. 系统定位

能力系统是游戏中的核心战斗子系统，负责管理角色的属性、技能、Buff/效果器等战斗相关能力，提供数据驱动的属性计算和效果施加机制。

## 2. 系统意义

- 提供统一的能力管理框架，整合属性、技能、Buff、效果器四大模块
- 支持属性依赖关系和派生属性计算，满足"每1点力量增加5点生命上限"等复杂数值需求
- 数据驱动的设计，通过配置表定义属性、技能、Buff，支持策划高效配置
- 支持周期性效果和持续性效果，如灼烧DOT、增益光环等
- 通过标签系统实现效果互斥、拦截和取消机制

## 4. 核心数据结构

### AbilityConfig
```lua
---@class AbilityConfig
---@field AbilityKey string 能力唯一标识
---@field AbilityName string 能力名称
---@field AbilityTemplate string 能力模板类路径
---@field AbilityCooldown number 冷却时间(秒)
---@field AbilityTags number[] 能力标签数组
---@field AbilitySkills table<string, string> 技能配置(EntrySkill等)
---@field AbilityTargetings table<string, string> 目标配置
---@field AbilityEffects table<string, string> 效果配置
---@field Projectiles table<string, string> 投射物配置
```

### SkillConfig
```lua
---@class SkillConfig
---@field SkillKey string 技能唯一标识
---@field SkillName string 技能名称
---@field SkillTemplate string 技能模板类路径
```

### AttrModifierClass
```lua
---@class AttrModifierClass
---@field public ModId integer 修改器唯一Id
---@field public ModAttrId integer 修改的属性类型(AttrDef中的Id)
---@field public ModValue integer 修改值
---@field public ModPriority integer 优先级
```

### EffectorConfig
```lua
---@class EffectorConfig
---@field EffectKey string 效果器唯一标识
---@field EffectDuration number 持续时间(-1表示永久)
---@field EffectPeroid number 触发周期(-1表示一次性)
---@field AttrImposeFml table 属性施加公式
---@field GrantedTags number[] 激活时授予的标签
---@field BlockByTags number[] 拦截标签(命中则拒绝施加)
---@field CancelTags number[] 取消标签(命中先移除再施加)
```

### BuffConfig
```lua
---@class BuffConfig
---@field public BuffKey string
---@field public BuffName string
---@field public BuffTemplate string Buff类模板路径
---@field public BuffPolicy BuffPolicyDef 时效策略
---@field public BuffDuration number 持续时间
---@field public Period number 周期
---@field public GrantedTags number[] 授予标签
---@field public BlockTags number[] 拦截标签
---@field public CancelTags number[] 取消标签
```

## 7. 执行流程

### 属性计算流程
1. 调用 `AttrSet:GetAttrValue(InAttrKey)` 获取属性
2. 若属性标记为脏(_Dirty[id] == true)，调用 `_UpdateAttribute` 重新计算
3. `_UpdateAttribute` 获取基础值(通过公式计算)，累加所有永久修改器
4. 触发 `_OnAttrChanged` 回调通知变更

### 效果器应用流程
1. 通过 `AbilityPart:MakeEffector(InEffectorKey)` 创建效果器实例
2. 设置 `EffectorSource` 和 `EffectorTarget`
3. 调用 `EffectorBase:InitEffector()` 初始化配置
4. 调用 `EffectorBase:CanActiveEffector()` 检查BlockTags
5. 调用 `EffectorBase:ActiveEffector(InTimestampSec)` 激活
6. 激活时授予GrantedTags，添加主动作修改器
7. 若存在周期(_Interval > 0)，在 `TickEffector` 中按周期触发 `ExecuteEffector`
8. 过期或手动调用 `InactiveEffector` 时移除标签和修改器

### Buff重入策略
- `BuffPolicyDef.HasDuration`: 有持续时间
- `BuffPolicyDef.Instant`: 即时生效
- `BuffPolicyDef.Infinite`: 永久持续直到被驱散
- ReapplyBuff处理重入: 重置/增强/独立/忽略/叠加

## 8. 使用示例

### 创建能力系统并为角色添加属性
```lua
local AbilitySystem = require("System/Ability/AbilitySystem")
local AbilityPartClass = require("System/Ability/Part/AbilityPart")
local AttrConfigClass = require("System/Ability/Attr/AttrConfig")

local system = AbilitySystem.Get()
system:InitAbilitySystem()

local part = AbilityPartClass:New(owner)
part:InitAttrSet("PlayerAttrSet")

local health = part:GetAttrSet():GetAttrValue("Health")
```

### 使用效果器施加持续伤害
```lua
local effector = part:MakeEffector("Fire")
if effector then
    part:ApplyEffectorToSelf(effector)
end
```

### 自定义Buff实现
```lua
local FireClass = Class3.Class("FireClass", BuffBaseClass)

function FireClass:ApplyBuff(InTimestampSec)
    BuffBaseClass.ApplyBuff(self, InTimestampSec)
    local modifier = AttrModifierFactoryClass.Get():AcquireModifier('BaseHealth', -10)
    self.BuffTarget:GetAttrSet():AddModifier(modifier)
end

function FireClass:DeactivateBuff()
    BuffBaseClass.DeactivateBuff(self)
    self.BuffTarget:GetAttrSet():RemoveModifier(self.fireModifier)
end
```

### 能力系统Tick驱动
```lua
function MyCharacter:Tick(DeltaTime)
    local timestamp = AbilitySystem.Get():GetTimestampSec()
    self._AbilityPart:TickAbilityPart(DeltaTime, timestamp)
end
```
