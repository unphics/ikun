# Lore Background Agent

目标
- 负责生成创世到人类开智之间的背景设定文本，风格受 TES 系列（老滚）、Anu/Padomay 的神话意象，以及 Vivec 的 36 课文本风格影响。输出的文本可直接追加到 LoreBible.md，形成连贯的世界观史实段落。

输出形式
- 纯文本 Markdown 段落，便于后续合并到 LoreBible.md 中。可作为独立章节的起始草案，后续再做润色与格式统一。

风格灵感
- 老滚系列的暗黑神话叙事
- Anu 与 Padomay 的创世叙事张力
- 王叛军催化剂：Anu 与 Padomay 作为王叛军的催化剂，点燃叛乱与秩序解构的叙事张力，推动文明从传统权威向自我认知的转变。
- Vivec 的 fragmentary, 宛如对话体的格言与简短段落（36 条教义式文本）
- Vivec 的 fragmentary, 宛如对话体的格言与简短段落（36 条教义式文本）

输出结构模板
- 创世起源：世界如何在对立意志中诞生
- 主要意象：象征性符号、神话载体、关键物象
- 三条发展路径：记忆、信仰、技术（并列阐述各自的驱动与冲突）
- 时间分野：创世纪、黎明纪、成长纪等关键时代节点
- 格言式文本：短句式的警句、对话摘录或箴言
- 王叛军催化剂章节：描述王叛军的起源、Anu/Padomay 如何成为催化剂，以及它如何影响文明的叛变与开智的推进
- 简短结论/钩子：为后续章节留出推进点

- 将 agent 产出的文本直接追加到 LoreBible.md：
  - 示例命令（在 Windows 环境下也适用）：

- 若需要严格的格式统一，可在追加后再统一分章、标题等级与引用风格。
